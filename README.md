# SJZ-s-Super-Quick-HD-Music-to-YT-Video-Converter
Solves the age-old problem of uploading full albums / mixtapes / DJ sets to YouTube in a quick &amp; efficient manner. Uses the open source FFMPEG (download separately) &amp; some FPS trickery to deliver a ~150MB output file at 1080p (.MP4) & 320kbps audio (.AAC), in about 5-10mins.

Because YouTube only requires a video to be rendered at 2FPS when it's just a static image with an audio file (rather than the standard 30-60FPS for moving image videos), this tool produces a compact output .MP4 file for direct YouTube upload -- about 150MB total filesize for a 1hr DJ mix, and the tool should take just ~7min to create the entire thing. Uploading to your channel will only take a few minutes more.

Audio quality is perfectly acceptable from this tool's output specs; a 1080p [HD] .mp4 with YouTube's preferred AAC 320kbps audio encoded from your source (which should be lossless WAV/FLAC/AIFF where possible).

Instructions are in the .bat file itself -- open it in Notepad and replace the necessary fields with your desired input & output paths (ie. where your image/audio files are located on your computer, and where you want the final video to be stored).
